# Security Policy

## Reporting a vulnerability

Report security issues privately through GitHub Security Advisories:

https://github.com/CubelliJ/harness/security/advisories/new

Do not open a public issue for leaked secrets, token theft, or remote code execution.

## Scope

Harness is a local CLI coding agent. It can run shell commands in the workspace
where you launch it. Do not run it against untrusted trees.
